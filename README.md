# Absher Demo (client preview)

Interactive demo of an Absher-style digital documents & services app.
**All data shown in the demo is sample data** (MD SAMPLE USER, ID 2000000000,
Passport A00000000) — no real personal information is included.

## Install the demo on a phone

1. Open the **Releases** section of this repository.
2. Download `app-debug.apk` from the **v1.0-demo** release.
3. Open the downloaded file on an Android phone and allow the install
   (the phone may ask to allow installs from the browser — this is a
   preview build signed with a debug key).

## What the demo shows

- Fingerprint / PIN lock screen
- Home with digital Resident ID & Driving License cards (QR / barcode)
- My Passport, Resident ID, Visa, Driving License and Travel Records pages
- Personal Details (Sponsor, Health Insurance, Hajj)
- My Services with service requests, Family and Workers sections
- Other Services with search

The full production app (real accounts, Saudi VPS backend and admin panel)
is described in the proposal shared with the client.
